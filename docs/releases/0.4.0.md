# 0.4.0 作者分身合同

通用实现已接入。真实作品的来源、作者机制、表达与整书验收继续按各私有任务推进；插件版本不等于书籍分身已通过，也不自动替换旧安装。

新蒸馏默认使用book-skill/2、book-eval/2：

- 完整论证或场景记录公开文本的推进、声音层次与读者效果，参与输入哈希。
- 画像、带条件与反证的习惯、可变路径联结思想动作、表达及完整范例；没有真实命题关系时可留空。
- 构建器逐字使用已审联合核心，生成画像及运行目标清单，保留单入口和按需查证。
- 作者认知与作者表达分开评分，绑定实际答文片段，逐项最低2分；正式验收需正常与变化情境的目标覆盖。
- 摘要与明确编写的材料移除对照只作诊断；匿名评审保留完整回答，分别绑定输出JSON和答文数组。
- v1继续按原合同读取和构建，标识thinking-v1，不能只改版本号获得作者分身身份。

程序四闸及vendor边界保留，未修改vendor源码。正式书籍仍由用户实际审阅完整回答后发布同一被测候选字节。

明确选择旧程序single/pack时只核当前Bundle、原文及四闸回执，不要求补造作者模型；已加入实际编译兼容回归。

2026-10-24回归：`make e2e`通过原程序12项、v1合同25项、v2合同15项；`make doctor`通过其适用检查。dsh宿主安装态在本机不适用，可选栅格出图缺密钥而跳过。合成夹具只验证合同，不能代替真实书籍评测。

迁移先固定原文、识别旧schema和安装，再补读重建episodes、author、habits、paths及联合核心，重新核查与实测。已有准确证据和程序可保留；旧分数不升格，未读未验继续列缺口。文件见[重建合同](../../skills/book-workflow/references/distill-thinking.md)，评分与发布见[验收协议](../../skills/book-workflow/references/evaluate-and-publish.md)。
