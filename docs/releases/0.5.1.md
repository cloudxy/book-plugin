## 接入变化

`scripts/bootstrap.py` 现在检查 HTML 客户端的实际版本：能够导入旧版不再等于就绪，版本不匹配时安装随包 wheel，并检查安装结果。已在当前工作区完成0.3.0→0.4.0升级，再次自举未重复安装。`bridge/render_html_image.py`、技能说明、四份带版本的插件清单同步到0.5.1；无密钥不调用出图服务，现有桥接仍仅提供本地 HTML/CSS 出图。
