实际字段版本为 `book-skill/1`。源内容变化会使旧语义复核失效；候选、题目、实际输出、评审和用户表达反馈分别绑定，结构通过不能授权发布。独立性、盲评和会话隔离仍依赖真实执行记录，字段本身不能证明人的独立性。

## 真实试点的范围

在工作区已有短篇经典中建立了一个选章试点，排除污染和未核实部分，保留旧产物。已有思想模型、叙事口吻、完整范例、短证据与23项独立来源复核；私有候选已在独立会话实际试答。

局部诊断比较无该书 Skill、实际旧版、原文检索与新版，并对同一道探索题作匿名语义和表达评审。新版、旧版与检索都有可成立的理解和推演；该题不足以证明新版存在总体增益。来源外引文也被作为实质错误记录。另保留陌生迁移、条件更新、篇幅和口吻的实际输出及复跑。

这些材料均在私有 `books/` 与 `.work/` 中，不随仓库发布。试点尚未完成15组全量、全部保留实例和用户目标口吻审阅；正式报告保持待完成，没有将试点安装成已验收产品。一次读取所有轮次的早期脚本演练仅作诊断，后续另作真正逐轮递交的试答。

## 使用与后续边界

开新宿主会话加载0.3.0。新书默认使用思想与叙事路径，旧书需要回读原文补蒸馏，插件更新不会自动把既有语料切片升级为思想体系。整书组合初版只有单入口，原程序 pack 的独立能力仍按旧模式工作。

具体书籍只有在完整回答、独立评审和用户口吻反馈通过后才能正式发布；未达到条件时保留可审阅试验包和具体缺口。宿主模型推演能力、原文质量和目标语体的效果继续按逐书证据判断。
